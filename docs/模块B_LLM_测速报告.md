## 结论

### 当前选择 (2026-05-23 起)

- **模型：** `Qwen/Qwen2.5-14B-Instruct`
- **温度：** `0.5`

相比旧配置（Qwen2.5-32B-Instruct, t=0.3）速度提升约 **2.4 倍**（4.6s vs 11.1s）。

### 温度对速度的影响

- **Qwen2.5-14B：** t=0.3 最慢（12.5s），t=0.5~0.7 最快（~4.7s），t=0.9 骤升到 11.9s
- **Qwen2.5-32B：** t 从 0.3 升到 0.7~0.9 有 ~20% 的加速（11.1s → 8.7s）
- **DeepSeek-V3：** 温度基本不影响速度（~11.5s 恒定），推测 API 端使用固定推理管线

### 速度异常说明

14B 在 t=0.3 和 t=0.9 时速度反而慢于 t=0.5/0.7，推测原因：
- **低温度（0.3）：** 模型倾向于选择概率最高的 token，输出更保守、token 序列可能更长
- **高温度（0.9）：** 采样空间大，模型可能在"发散探索"中生成了更多细节描述
- **中等温度（0.5~0.7）：** 平衡点，输出长度和生成速度最佳
