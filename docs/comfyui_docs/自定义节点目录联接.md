# ComfyUI 自定义节点目录联接

## 1. 目标

当前项目将：

```text
src/music_video_pipeline/comfyui/custom_nodes
```

视为 **唯一真实自定义节点仓**。

ComfyUI 侧不再按“每个节点目录单独建一条软链接”的方式维护，而是直接把：

```text
G:\ComfyUI\custom_nodes
```

整体联接到项目目录：

```text
M:\MyTest\working\music_video_pipeline\src\music_video_pipeline\comfyui\custom_nodes
```

这样做之后：

1. `mvpl_comic_alpha`、`mvpl_grayscale` 等节点都在同一目录下统一维护。
2. 新增自定义节点子目录后，无需再额外创建新的链接。
3. 重启 ComfyUI 后，新节点会自动被扫描到。

---

## 2. 当前目录结构

项目内当前约定结构如下：

```text
src/music_video_pipeline/comfyui/custom_nodes/
  ComfyUI-DynamiCrafterWrapper/
  ComfyUI-Manager/
  mvpl_comic_alpha/
  mvpl_grayscale/
```

其中：

- `mvpl_comic_alpha` 当前提供 `MVPL: ExtractComicAlpha`
- `mvpl_grayscale` 当前提供 `MVPL: ConvertToGrayscale`

---

## 3. Windows 使用 Junction

### 3.1 前提

1. 先关闭 ComfyUI。
2. 确认 `G:\ComfyUI\custom_nodes` 当前不是你仍需保留的真实目录。
3. 如需保留旧内容，先备份或改名。

### 3.2 推荐方式

Windows 下统一使用目录联接（Junction）。

如果需要保留旧目录，先改名：

```powershell
Rename-Item G:\ComfyUI\custom_nodes custom_nodes_backup
```

然后创建目录联接：

```powershell
New-Item -ItemType Junction `
  -Path G:\ComfyUI\custom_nodes `
  -Target M:\MyTest\working\music_video_pipeline\src\music_video_pipeline\comfyui\custom_nodes
```

### 3.3 验证

执行：

```powershell
Get-Item G:\ComfyUI\custom_nodes | Select-Object FullName,LinkType,Target
Get-ChildItem G:\ComfyUI\custom_nodes
```

预期结果：

1. `LinkType` 为 `Junction`
2. 能直接看到 `mvpl_comic_alpha`、`mvpl_grayscale` 等子目录

---

## 4. Linux 使用符号链接

先关闭 ComfyUI，然后执行：

```bash
mv /path/to/ComfyUI/custom_nodes /path/to/ComfyUI/custom_nodes_backup
ln -s \
  /path/to/music_video_pipeline/src/music_video_pipeline/comfyui/custom_nodes \
  /path/to/ComfyUI/custom_nodes
```

验证：

```bash
ls -l /path/to/ComfyUI
ls -l /path/to/ComfyUI/custom_nodes
```

应能看到 `custom_nodes -> ...`，且目录下能列出项目内的节点子目录。

---

## 5. 日常维护规则

1. 自定义节点源码只在项目目录 `src/music_video_pipeline/comfyui/custom_nodes/` 内修改。
2. `G:\ComfyUI\custom_nodes` 仅作为联接入口，不直接手改。
3. 新增节点时，直接在项目目录下新建子目录即可，不再为单个节点额外建链接。
4. 如果节点名、节点映射或工作流节点类型发生变化，必须同步更新：
   - 对应节点目录中的 `NODE_CLASS_MAPPINGS`
   - `configs/comfyui/workflows/*.workflow_api.json`
   - `configs/comfyui/workflows/*.gui.json`
5. 如果 ComfyUI 被重装，恢复后优先重建整目录联接，再启动 ComfyUI。

---

## 6. 重建步骤

当联接失效或 ComfyUI 目录被清理后，按以下顺序恢复：

1. 关闭 ComfyUI。
2. 删除失效的 `G:\ComfyUI\custom_nodes`。
3. 按本文件的 Junction 命令重新创建整目录联接。
4. 重启 ComfyUI。
5. 在节点搜索中确认 `MVPL: ExtractComicAlpha` 与 `MVPL: ConvertToGrayscale` 可见。
