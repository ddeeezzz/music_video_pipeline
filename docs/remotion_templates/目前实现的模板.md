# 目前实现的模板

## CenterTemplate

### 自然语言描述

画面中央显示 1 张图。

- 如果 `breathe=true`，图片会轻微呼吸
- 如果 `breathe=false`，图片就静止显示

### props 结构

```json
{
  "template": "center",
  "fps": 24,
  "duration_in_frames": 48,
  "bpm": 130,
  "background": {
    "kind": "solid",
    "color": "#FFFFFF"
  },
  "symbol": {
    "src": "/fixtures/center-symbol.svg",
    "width_ratio": 0.42,
    "height_ratio": 0.42
  },
  "motion": {
    "breathe": true
  }
}
```

### 参数解释

- `template`
  - 固定写 `"center"`
- `fps`
  - 视频帧率
- `duration_in_frames`
  - 这一段总帧数
- `bpm`
  - 当前段落的 BPM
  - 目前呼吸频次仍然参考它
- `background.kind`
  - 背景类型
  - 可选：`none`、`solid`、`image`、`video`
- `background.color`
  - 当背景是纯色时使用
- `background.src`
  - 当背景是图片或视频时使用
- `symbol.src`
  - 中央这张图的资源路径
- `symbol.width_ratio`
  - 这张图相对画面宽度的比例
- `symbol.height_ratio`
  - 这张图相对画面高度的比例
- `motion.breathe`
  - 是否启用呼吸动画

## GridTemplate

### 自然语言描述

画面里横向摆 3 张图，依次跳出来。

- 横向按格子平均排布
- 纵向居中排布
- `visible_cell_count` 决定一张完整静态图占几个格子
- `active_ratio` 决定三张图完成跳出的时间，占整段时长的多少比例

### props 结构

```json
{
  "template": "grid",
  "fps": 24,
  "duration_in_frames": 84,
  "bpm": 130,
  "background": {
    "kind": "solid",
    "color": "#FFFFFF"
  },
  "symbols": [
    {
      "src": "/fixtures/grid-a.svg",
      "width_ratio": 0.26,
      "height_ratio": 0.52
    },
    {
      "src": "/fixtures/grid-b.svg",
      "width_ratio": 0.26,
      "height_ratio": 0.52
    },
    {
      "src": "/fixtures/grid-c.svg",
      "width_ratio": 0.26,
      "height_ratio": 0.52
    }
  ],
  "layout": {
    "visible_cell_count": 3
  },
  "motion": {
    "active_ratio": 0.45,
    "overshoot_ratio": 0.08,
    "enter_distance": 72
  }
}
```

### 参数解释

- `template`
  - 固定写 `"grid"`
- `fps`
  - 视频帧率
- `duration_in_frames`
  - 这一段总帧数
- `bpm`
  - 当前段落的 BPM
- `background.kind`
  - 背景类型
  - 可选：`none`、`solid`、`image`、`video`
- `background.color`
  - 当背景是纯色时使用
- `background.src`
  - 当背景是图片或视频时使用
- `symbols`
  - 固定 3 张图
- `symbols[i].src`
  - 第 `i` 张图的资源路径
- `symbols[i].width_ratio`
  - 第 `i` 张图相对画面宽度的比例
- `symbols[i].height_ratio`
  - 第 `i` 张图相对画面高度的比例
- `layout.visible_cell_count`
  - 一张完整静态图占几个格子
- `motion.active_ratio`
  - 三张图完成跳出的时间，占整段时长的比例
- `motion.overshoot_ratio`
  - 入场时缩放会比最终大小多冲出去多少
- `motion.enter_distance`
  - 入场开始时离最终位置有多远

## ScrollTemplate

### 自然语言描述

画面里横向排 3 张图，整体向左滚动。

- `visible_cell_count` 决定一张完整静态图占几个格子
- `loop=false` 时，整段时长内滚完一轮
- `loop=true` 时，进入循环滚动

### props 结构

```json
{
  "template": "scroll",
  "fps": 24,
  "duration_in_frames": 144,
  "bpm": 130,
  "background": {
    "kind": "solid",
    "color": "#FFFFFF"
  },
  "symbols": [
    {
      "src": "/fixtures/scroll-symbol.svg",
      "width_ratio": 0.28,
      "height_ratio": 0.72
    },
    {
      "src": "/fixtures/scroll-symbol.svg",
      "width_ratio": 0.28,
      "height_ratio": 0.72
    },
    {
      "src": "/fixtures/scroll-symbol.svg",
      "width_ratio": 0.28,
      "height_ratio": 0.72
    }
  ],
  "layout": {
    "visible_cell_count": 3
  },
  "motion": {
    "loop": false
  }
}
```

  - 背景类型

  - 当背景是纯色时使用
